# 꼬리의 하루 🌱

사진 속 강아지의 접힌 귀, 갈색 눈썹과 까만 주둥이를 참고해 만든 한국어 2D 힐링 게임. 정원에서 작은 친구를 돌보며 아기 → 청소년 → 어른으로 함께 자랍니다.

- 밥 주기, 쓰다듬기, 공놀이, 꽃 찾기 산책, 낮잠
- 사랑 100 / 250에서 성장, 낮잠 후 다음 날, 하루 목표 보너스
- 이름 변경, 추억 일기, 낮/밤 전환, 선택 가능한 작은 효과음
- 브라우저 자동 저장 및 JSON 내보내기/불러오기
- 모바일, 키보드 조작, 모션 감소 설정 지원
- 접속하지 않는 동안에는 수치가 줄지 않습니다.

원본 사진은 공개 저장소에 포함하지 않았습니다. 캐릭터와 배경은 직접 작성한 SVG입니다. 폰트는 Google Fonts의 고운돋움과 고운바탕이며, 로딩할 수 없을 때는 기기 기본 글꼴을 사용합니다.

## 실행

```sh
npm ci
npm run dev
npm test
npm run build
```

실제 브라우저 통합 검사:

```sh
npx playwright install chromium
TEST_URL=http://localhost:5173/ node scripts/check.mjs
```

`main`에 push하면 GitHub Actions가 테스트와 빌드 후 GitHub Pages에 배포합니다. 정적 파일만 사용하며 서버나 API 키가 필요하지 않습니다. 저장은 기기/브라우저별로 분리됩니다.
