# 꼬리의 하루 · 바람 따라, 꼬리 따라

**[게임 플레이](https://hex-aragon.github.io/pawful-days/)**

강아지가 가로로 달리고, 점프해 나무 발판과 개울을 건너는 2D 횡스크롤 육성 게임입니다. 「하얀마음 백구」의 실제 게임 화면을 조사하여 옆에서 보는 시점, 횡스크롤, 발판과 수집물의 화면 구성을 참고했습니다. 기존 탑다운 맵 버전은 이 버전으로 교체되었습니다.

## 캐릭터와 애니메이션

- 백구, 황구, 흑구, 사용자가 제공한 강아지 사진의 갈색/검정 배색을 선택합니다.
- 내장 이미지 생성 도구로 만든 6프레임 달리기 사이클과 별도의 서 있기/앉기/점프/착지 그림을 사용합니다.
- 달리는 속도와 프레임 진행이 연결되고, 방향 전환, 공중 점프, 착지 상태가 각각 반영됩니다.
- 사진 속 친구는 접힌 귀, 검은 주둥이와 등, 갈색 눈썹/볼, 크림색 가슴을 참고했습니다.

## 플레이

- 좌우 방향키 / A D: 달리기
- Shift: 빠르게 달리기
- Space / 위 방향키 / W: 점프, 공중에서 한 번 더 점프
- E: 밥 먹기, 쉬기, 공 던지고 직접 가져오기, 친구와 인사하기
- P / Esc: 일시정지
- 모바일: 왼쪽 방향 버튼 + 오른쪽 점프/달리기 버튼

햇살 들판 → 바람 숲길 → 반짝 개울, 세 코스를 순서대로 엽니다. 중간 깃발이 체크포인트이며 물에 빠지면 가장 최근 깃발에서 다시 출발합니다. 사랑 100에 청소년, 250에 성견이 되며 실제 캐릭터가 커집니다. 성장, 이름, 털색, 완료 코스, 수집물, 체크포인트를 브라우저에 저장합니다. 기존 v1/v2 저장은 이름과 성장 점수를 가져옵니다. 메뉴에서 성장 기록을 JSON으로 내보내거나 불러올 수 있습니다.

## 실행과 검사

```sh
npm ci
npm run dev
npm test
npm run build
```

실제 브라우저 검사 (서버 실행 필요):

```sh
npx playwright install chromium
TEST_URL=http://localhost:5173/ node scripts/check.mjs
```

검사 범위: 네 가지 털색, 저장값 정규화, 성장 경계, 달리기/2단 점프/착지 물리, 세 코스의 완주 가능성, 실제 브라우저 입력으로 첫 코스 전체 완주, 코스 해금, 이름과 털색 저장, 모바일 이동/점프. 브라우저 테스트는 캐릭터를 순간 이동시키지 않고 실제 키 입력으로 첫 코스를 통과합니다.

## 이미지와 참고 자료

최종 그림은 모두 `public/art/`에 있습니다. 제작 모드는 **내장 image_gen 도구**이며 프롬프트는 [`public/art/prompts.json`](public/art/prompts.json)에 기록했습니다.

- `dogs-run.png`: 4종 × 6프레임 달리기 아틀라스
- `dogs-poses.png`: 4종 × 대기/앉기/점프/착지 아틀라스
- `spring-valley.png`, `forest-path.png`, `river-light.png`: 코스별 배경
- `meadow-ground.png`: 풀과 흙 지형 텍스처

게임의 텍스처 로더가 단색 마젠타 배경을 투명하게 처리하고 각 프레임을 추출합니다. 원본 사진이나 원작 게임 그래픽은 공개 저장소에 포함하지 않았습니다.
