# 꼬리의 하루 — 작은 발로 떠나는 모험

**[게임 플레이](https://hex-aragon.github.io/pawful-days/)**

사진 속 강아지의 접힌 귀, 갈색 눈썹과 까만 주둥이를 참고한 2D 탐험 육성 게임입니다. 강아지를 직접 움직여 마을·초원·숲·호수를 돌아다닙니다. Canvas로 그린 연속된 2800 × 2000 맵, 강아지를 따라가는 카메라, 네 다리와 귀·꼬리의 걷기 애니메이션을 사용합니다.

## 조작

- 방향키 / WASD: 이동
- Shift: 달리기
- E / Space: 가까운 NPC 또는 사물과 상호작용
- M: 지도
- 모바일: 왼쪽 조이스틱 + 오른쪽 행동/달리기 버튼

## 모험과 성장

집 앞 할머니와 인사하고, 밥그릇에서 식사하고, 초원 꽃을 모으고, 던져진 공을 직접 쫓아가 회수합니다. 숲의 친구 두리를 만나 함께 걷고, 호수의 다리를 건넌 뒤 집 방석에서 쉬어 다음 날을 맞습니다. 일곱 개의 작은 모험 이후에도 자유롭게 돌아다니며 육성할 수 있습니다.

사랑 100에서 청소년, 250에서 어른이 되며 실제 캐릭터 크기가 커집니다. 낮잠 후 꽃이 다시 피고, 방문하지 않는 동안 수치가 감소하지 않습니다. 브라우저별 자동 저장, 이름 변경, 추억 일기, JSON 내보내기/불러오기와 기존 v1 기록 이전을 지원합니다. 위치가 곤란하면 메뉴의 '집 앞 길로 돌아오기'를 사용할 수 있습니다.

원본 사진은 공개 저장소에 포함하지 않았습니다. 캐릭터와 배경은 직접 작성한 Canvas/SVG 드로잉입니다. Google Fonts 고운돋움/고운바탕을 사용하며 불러올 수 없을 때는 시스템 글꼴로 표시합니다. 서버와 API 키는 필요 없습니다.

## 개발 및 검사

```sh
npm ci
npm run dev
npm test
npm run build
```

브라우저 통합 검사 (개발 서버가 실행 중이어야 합니다):

```sh
npx playwright install chromium
TEST_URL=http://localhost:5173/ node scripts/check.mjs
```

단위 검사: 성장과 저장 데이터, 충돌, 모든 주요 지점 및 꽃으로의 길 연결.
브라우저 검사: 실제 키보드 이동, NPC/돌봄/퀘스트, 꽃 줍기, 공 회수, 성장, 저장 복원, 지도 및 모바일 조이스틱. 개별 지역 시나리오는 저장 위치 fixture로 설정하며 조작과 상호작용은 브라우저 입력으로 검증합니다.

GitHub Actions가 main push 시 테스트와 빌드 후 GitHub Pages에 자동 배포합니다.
